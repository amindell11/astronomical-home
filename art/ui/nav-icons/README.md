# Nav icons

One family for every navigation marker: finds on the minimap (mod, repair, armory),
the exit and lull beacons on the minimap and at the screen edge, and the enemy
pointer the off-screen enemy work picks up later. The container tells the role
(finds are diamonds, exit is a circle, lull is a hexagon, enemy is a triangle);
the dark glyph tells the kind; each kind has its own colour.
The PR that shipped it holds the rejected options:
[#1516](https://github.com/amindell11/astronomical-home/issues/1516) links it.

## Files

| File | Role |
|---|---|
| `settings.json` | The owner's tuned knobs. The one source for shape, size and colour. |
| `icons.js` | The icon geometry: settings in, SVG out. The tuner page and the export both run it. |
| `navicons.py` | Bakes the SVGs, a game-scale preview, the tuner page and the Unity sprites. |
| `tuner.template.html` | The tuner page; `navicons.py --tuner` fills in `icons.js` and `settings.json`. |
| `svg/` | The coloured icons, regenerated by every run. |

## Regenerate

```bash
cd art/ui/nav-icons
uv run navicons.py                                            # svg/ and out/lineup.png
uv run navicons.py --tuner out/tuner.html                     # publish it with the Artifact tool
uv run navicons.py --export ../../../src/Asteroids3D/Assets/Visuals/Ui
```

Needs `node` on the path. The tuner's Copy settings block pastes over `settings.json`.

## In Unity

The export writes white sprites with ink glyphs. The game tints them: finds through
`FindColours.Of`, beacons through `ObjectiveMarkers`' exit and lull colours. Keep
those colours equal to `settings.json`. Arrow tabs are drawn by `NavTab`, whose
constants copy the settings' tab size, tab gap and container sizes.
The HUD adds its light on top of the scene, so the ink glyphs read as windows onto
the sky; the tuner's "With the HUD look" panel shows that.
