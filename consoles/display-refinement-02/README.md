# Hull diagram at console size

The owner selected B, Hull diagram, then rejected the density of the entire concept batch. This refinement keeps the diagram but tests it inside the limited screen area of the approved console.

Open the [review](index.html) for the full game-window view and an enlarged screen. The [full scene](full-scene.png) shows the readability test; the [close-up](screen-closeup.png) is for inspecting the shapes and type.

The screen removes description placeholders, weapon stat sentences, long fitted-part names and repeated explanatory labels. The ship silhouette and equipment glyphs carry the first read. Six real ship values remain as short callouts with simple segmented bars. The Dash cooldown and the two weapon identities remain visible.

This is a native screen layout placed over [the approved glass image](../refinement-04/viewport-glass.png). It reuses the exact [font and icon assets](../display-concepts-01/assets/provenance.json) and [verified data](../display-concepts-01/assets/screen-data.json) from the preceding batch. The hardware, exterior labels and physical Launch button stay for a later pass. No Blender or game files changed.

[Render checks](render-checks.json) confirm the six values, actual fonts and glyphs, and no clipped content. The [pixel comparison](pixel-checks.json) found no changes outside the display footprint, with one pixel allowed at its antialiased boundary. The [native screen crop](screen-native.png) preserves its 286 by 314 reading size; the close-up enlarges that view three times.
