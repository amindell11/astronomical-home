# Console lit by electronics

The owner [asked for dim controls lit mainly by the screens and hologram](https://github.com/amindell11/astronomical-home/issues/684#issuecomment-6516350712), with little ambient starlight. This revises the restored image's lighting. It does not resume the rejected live rebuild.

Open [the comparison](index.html). It starts on `electronic-light-contrast-nb2.jpg`, the console session's recommendation after visual review and two follow-up reviews with the Claude UI session. The warm light on the inner bezel and deep hardware shadows best express the requested contrast. This is a review recommendation, not an owner selection.

The comparison also offers `electronic-light-contrast-pro.jpg`, which keeps the brighter space view, and the exact restored input. The stronger nb2 result darkens and desaturates the distant nebula and makes the emitter a more distinct bright rectangle. Those are visible incidental changes. The pro alternative retains more of the original space and emitter appearance, with weaker screen spill and lighter hardware. Neither output changes the loadout text or principal ship silhouette at display scale. Image generation resynthesizes pixels, so neither is pixel-identical outside the relit areas.

`electronic-light-nb2.jpg` and `electronic-light-pro.jpg` preserve the first, weaker lighting pass. The second prompt strengthens the same lighting direction. Both prompts ran nb2 and pro through the repo Gemini image CLI. Prompts, returned provenance sidecars and inputs are saved here. Image 1 is the restored console edit target. Image 2 is the owner's existing dark cockpit reference, used only for lighting mood.

The image and text were visually inspected. The comparison loads all three full-resolution views and switches between them without page errors. Shared fonts and tuners, game code and game assets are untouched. All work happened outside the primary tree.
