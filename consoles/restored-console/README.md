# Restored console

The owner [rejected the live rebuild](https://github.com/amindell11/astronomical-home/issues/684#issuecomment-6510846322) and asked to return to the old version, make the ship a bit more transparent, and stop.

The restored base is `../hologram-01/05-color-hologram-pro.jpg`, the leading console image in the earlier joint HTML review. The [current page](index.html) shows `opacity-only-nb2.jpg`, a modest transparency-only edit. The original menu, typography, hardware, ship geometry, colors and composition remain the design. No further type, effects or geometry work follows this adjustment.

The repo image tool ran nb2 and pro from that single edit target. Both results and sidecars are preserved; nb2 is the displayed result. Prompt and input are saved here. The images were visually compared against the base. Image generation resynthesizes pixels, so this is not a claim of pixel-identical preservation outside the ship. No game code or assets changed.
