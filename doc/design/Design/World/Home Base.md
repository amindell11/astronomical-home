You respawn in home base. Here you can:

- **Craft**: use parts and items found along the way to create new ship items and upgrades.
- **Choose contracts**: goals for each run that give permanent rewards. Random contracts spawn each time, and the player chooses one to pursue in the current run.
- **Simulated drill field**: fly your current build and test it against your AI companion. If you die, there is no penalty; you simply return to base.
- **Ship build hangar**: choose your [[Ships|Ship]] setup (engine, etc.; details TBD).
