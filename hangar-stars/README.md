# Stars-only hangar: larger ship previews

The accepted change enlarges the original ShipPreview rectangle from 880 x 880 to 1200 x 1200 canvas units, about 36% in each dimension. No preview code, lighting, background, ship art, rotation or switch animation changes are included.

Crimson_Preview.png, Nightshade_Preview.png, Valis_Preview.png and Vanguard_Preview.png show the four existing ships at 1600 x 900. Vanguard-before.png shows the original smaller preview at the same pose as Vanguard_Preview.png. Vanguard-16x10.png and vanguard-21x9.png show the larger preview at 1440 x 900 and 2100 x 900 respectively. Window-resize-diagnostic.png is an intermediate editor resolution diagnostic, not one of the final aspect-ratio captures.

Ship rotation was paused temporarily to capture comparable stills. The production preview retains its original rotation and switch behavior. Stills do not establish animation timing.

The earlier hangar/ images record the cancelled illustrated-floor direction. They are historical evidence, not the final requested change.
