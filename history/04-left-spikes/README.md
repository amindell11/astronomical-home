# B1 without the left spikes

The user requested a variant without the spikes to the left of B1's contact point. The built-in image generator removed the backward starburst and replaced it with a compact blunt contact edge, retaining the broad rightward fan and its color bands. The original B1 and its cleanup working file remain preserved.

`b1-no-left-spikes.png` is the unchanged generated variant with transparent alpha. Its JSON sidecar contains the exact edit prompt and parent reference hash. `index.html` compares it with the original at the same canvas scale, enlarged and at approximate gameplay size. `comparison.png` captures that page.

This is a requested shape variant awaiting user review. It is not a hand-cleaned generator source or an in-engine capture.
