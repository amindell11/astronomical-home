# Growing spike and oblique mine blast

The upright spike grows by extending both complete outer sections while the
central burst keeps its shape. It reaches full length at 180 ms and fades with
the existing 400 ms core. The disc keeps its 800 ms sweep.

The perspective comparison shows the circular version, a compressed oblique disc,
and the oblique disc with a faint circular range ripple. The user selected the
range ripple. The shared drawing preview now shows that choice at large and game
scale. The bright disc is 28% as tall as wide; the circular ripple has 28% opacity.

These are drawing previews from the shared texture renderer. Unity capture will
be appended after import and verification. Earlier stages remain for comparison.
