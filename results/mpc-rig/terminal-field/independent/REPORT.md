Earlier capture attempts are retained but excluded from comparison. Recorder 5.1.2 variable-rate initialization leaves its frame interval zero; its padding-reset path then clears `Time.captureDeltaTime`. This produced only about 270 frames for 40 simulated seconds. Turning the editor auto-tick off did not fix it. The narrow integration correction initializes Recorder in constant mode, then enables variable-rate skipping after successful start. It preserves the existing every-fifth-frame cadence without resetting time each step. This is an initialization fix (fix-ladder rung 2), not an error-absorbing guard. The other measured error was a 25 m phantom path segment from reading ship kinematics before its first fixed update; initializing the counter from the authored spawn position removes it. Both corrections are exercised by the final paired runs. The Recorder integration change is the only additional shared-capture change and is flagged for scope review before any submission.

## Correctness and experiments

- Latest full MPC selection: 123 passed, one failed frozen-benefit acceptance test, nine opt-in skips. The earlier MPC regression run passed 123 with seven skips before final validation was enabled.
- Field correctness includes an independent shortest-path oracle over 200 random grids, occupied/disconnected sampling, diagonal corner restrictions, explicit clearance cases, cadence/reset, weighting and absent-source behavior.
- A direct-SolverBuffers regression exposed unassigned native arrays for absent fields. The owned empty-array representation fixed the job scheduling failure; the existing MPC tests then passed.
- Development retained all weight sweeps, including poor candidates. Conservative disc/cell-square rasterization overblocked a physically clear gap as far goals enlarged spacing. Center membership removed the extra cell footprint. At very coarse spacing it can miss small obstacles; the 360 m far-goal probe demonstrates this aliasing limitation.
- Six-row, four-arm development session matrices were run at several weights. At final weight 0.03, all six movement-error median comparisons pass and dummy closeout improves from 16.58 to 10.74 s. Cover collision steps increase from 19 to 34 and fire-lane steps from 3 to 9. These development collision regressions are not concealed by the passing transit collision check.
- A separate 280-episode rig matrix records all four shaping-cost arms with collision penalty enabled. It is diagnostic evidence, not a substitute for the real-session acceptance matrix.
