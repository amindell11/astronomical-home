# Line sheet

The game's companion and enemy lines. This tab exports to LineSheet.txt in the repo, and the game reads its lines from that file. Edit here, then export. The export is markdown, but the repo copy is named .txt so that every line change runs the game's tests before it lands.

- Only rows whose Status is "In game" load. "Later" rows wait for a feature the game doesn't have yet, and the Notes cell says which.
- A blank Faction means any sector.
- A blank After opens the exchange. "any" follows any opening line from another speaker in the same moment and faction. An ID follows only that line.
- Rows that share a moment, faction and speaker are interchangeable, and the game picks one at random.
- An ID is never reused, even after its row is cut.
