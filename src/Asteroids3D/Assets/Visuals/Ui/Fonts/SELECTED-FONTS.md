# Selected combat HUD fonts

Both files are unmodified upstream static Medium faces, with OS/2 weight 500.
Use FontStyle.Normal; their outlines already carry the selected weight.

- `Orbitron-Medium.ttf`: [upstream static face](https://github.com/googlefonts/orbitron-vf/blob/f16482824e0ce4d008dee59b9b632e9ce9663359/fonts/ttf/Orbitron-Medium.ttf).
  This is the source commit recorded by [Google Fonts metadata](https://github.com/google/fonts/blob/6157dfaa640ca5738b4d1a7070fe389c3036d7fc/ofl/orbitron/METADATA.pb).
  SHA-256: `bc96ab93d786e3417b92285b96cdfe40a3de263930ee99eebfd4e19a756df8d2`.
  The reserved Orbitron name is retained on the unmodified upstream file.
  License: `Orbitron-LICENSE.txt`.
- `Rajdhani-Medium.ttf`: [Google Fonts static face](https://github.com/google/fonts/blob/6157dfaa640ca5738b4d1a7070fe389c3036d7fc/ofl/rajdhani/Rajdhani-Medium.ttf).
  SHA-256: `12ff7dcfe4c206e3875ac53b1762eab57de6a2fa7f5a86c26b97b88d6591eac2`.
  License: `Rajdhani-LICENSE.txt`.

Glyph outlines and advances are unchanged, including Orbitron's proportional digits.
